# Skip end-to-end checks for low-risk tasks

- Phase 4 now also skips a typo and a reformat. Read-only work stays exempt.
- One header line skips Phases 3 and 4 for a mechanical git task, unless asked. A conflict resolution that writes anything beyond picking a side is not mechanical.
- A skipped Phase 4 still prints its `e2e: n/a` line.
- `review-tiers.md` and the repo `CLAUDE.md` defer to the Phase 4 scope.
- Why: an e2e run on a merge, push or conflict resolution costs time and finds nothing.
