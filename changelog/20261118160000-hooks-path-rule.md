# Activate tracked git hooks in each clone

- Added `## Hooks` to `rules/git-ship.md`: a repo with a tracked `.githooks/` and no `core.hooksPath` makes the agent get a yes before it runs `git config core.hooksPath .githooks` before the first commit.
- Why: `core.hooksPath` is per clone, so a new clone ran without the repo's pre-commit checks.
- Why ask first: the setting stays in the clone's local config and runs the tracked hook code on every later git command, also the user's own.
