# Pair the design skills in builder.md

- Added a Design section to `rules/builder.md`. New UI or a redesign in a greenfield or side project loads the `frontend-design` skill and the `hallmark` skill together, and the `hallmark` hard gates win when the two skills disagree.
- Widened the `builder.md` frontmatter description and the `rules/` bullet in `CLAUDE.md` to cover new UI design.
- Why: each skill fired on its own description only, so a design task could load one skill and miss the other. The two skills also conflict when no precedence is stated.
