# Add brainstorm skill

- Added the `brainstorm` skill: rephrase the problem, generate ideas through inversion, analogy and constraint, replace the obvious ones, score impact and effort, shortlist the top 3, and give one next step.
- Added its README row with `rephrase` as a dependency, so the restricted `rephrase` skill can run from step 0.
- Why: gives a repeatable ideation flow that stays separate from judging one idea (`council-v2`), attacking a plan (`grill-me`) and planning execution (`goal-breakdown`).
