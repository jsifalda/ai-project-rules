# Plan outage recovery one attempt at a time

- Added a rule under `# PLAN MODE DEFAULT` in `rules/general.md`: plan an outage recovery one attempt at a time, and report each result before you plan the next attempt.
- Why: a recovery plan that lists every fallback commits to attempts before the user sees the result of the first one. The user wants to decide each next step from that result.
- Shortened the established-product rule in the same section, with the same meaning, so that the always-loaded file grows less.
