# Move optimize-my-cv to a private skills tree

- Moved the `optimize-my-cv` skill out to a private tree. Removed it from this repo and from the
  README table.
- Why: the skill is worth tailoring with real CV data, employer names and target-role positioning,
  and this repo's universality requirement forbids all of that. A private tree removes the block.
- The skill was universal as it stood, so nothing had to be sanitized before the move, and its copy
  stays in this repo's history by choice. No history rewrite.
- No dependency change. Nothing here depended on the skill, and it depended on nothing.
