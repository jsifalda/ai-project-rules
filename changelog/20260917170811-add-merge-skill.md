# Add the `merge` skill

- Added `skills/merge/SKILL.md`, invoked with `/merge`. It fetches the remote default branch,
  merges it into the current branch, resolves conflicts, runs the project's own gates, and
  pushes only the current branch to its own upstream. Added its row to the README skills table.
- The prompt "fetch main, merge here, resolve conflicts, push to the PR" was typed by hand at
  the end of most worktree sessions, and each time the agent had to rediscover the same traps.
  In a linked worktree the default branch is checked out elsewhere, the stash stack is shared,
  and the branch is already on a PR. The skill fixes the safe sequence once. It never rebases,
  never force-pushes, never stashes, and refuses to push the default branch.
- The base remote and the push remote are resolved separately, so a fork setup with `upstream`
  works. A merge stopped on a decision conflict resumes on the next `/merge` run.
