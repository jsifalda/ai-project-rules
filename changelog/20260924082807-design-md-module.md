# Add DESIGN.md module to setup-aiengineering

- Added a "Design source of truth" module: UI repos get a `DESIGN.md` in the Google DESIGN.md format, backfilled from existing UI code or authored with the user using the `frontend-design` and `hallmark` principles.
- Injects a `## Design` rule block into the agent instructions and a blocking Design-in-sync verification gate, so agents obey `DESIGN.md` and update it in the same change as any visual change.
- Bumped the skill baseline to v16, so re-runs offer the module to older setups.
- Why: agents restyled UI ad hoc, drifted from the existing look, and fell back to generic AI aesthetics. One design file now governs.
