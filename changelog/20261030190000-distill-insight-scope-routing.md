# Route distill-insight rules by scope and cap redrafts

- Pick the save target after the redraft steps end, and send a rule that fits every project to the global or shared rules even when a project file exists.
- Let a project rule name the project's own tools without a redraft.
- Cap redrafts at two, name the tests the best draft still fails, and record each rejected narrower draft.
- Why: the project file always won, so a universal rule landed in one repo, and the up and down redraft steps had no exit.
